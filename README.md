# Recipe App

The Recipe App is an Android application that provides users with a comprehensive cooking experience. Users can search for various dishes, filter them based on country cuisine, view detailed cooking instructions, and watch related YouTube videos. Additionally, users can add dishes to their favorites for easy access later.

## 🌟 Features
- **Search and Filter Dishes**: Search for their favorite dishes and apply filters based on different countries' cuisines.
- **View Dish Details**: View detailed cooking instructions, and recipes, and watch YouTube videos related to the dish.
- **Favorites Section**: Add recipes to your favorites for easy access later.

## 📚 Tech Stack
- **Multi-Module Architecture**
- **Jetpack Compose**
- **Type-Safe Navigation**
- **Room Database**
- **Retrofit**
